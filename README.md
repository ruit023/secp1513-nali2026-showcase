## 📌 Featured Poster: *ElektroTutor AI*

**Title:** *ElektroTutor AI: A Bilingual 3D-Avatar Voice Tutor for TVET Electrical & Electronics*  
**Innovators:** Muhammad Khair Noordin & Muhammad Afandi Azmi (Faculty of Educational Sciences and Technology, UTM)

| Dimension | Key Highlight |
| :--- | :--- |
| **Lab Problem Solved** | Addresses the challenge of one lecturer supporting 50 benches at once while learners juggle circuit wiring, pin placements, and microcontroller coding. |
| **Bilingual Voice Mentor** | *Cikgu Elektro* supports real-time Malay–English voice interaction, allowing hands-free guidance while keeping technical/exam terms clear. |
| **Real-Time & Offline Edge** | Built around low-latency interaction (~850 ms response, barge-in support), pin-by-pin wiring & Arduino code views, and a zero-install single-HTML setup suited for weak lab networks. |
| **Pilot Impact** | Reported a **63.3%** test-score gain across a 4-week UTM pilot (`n = 54`), with **88%** of learners favoring voice over typing for hands-free lab work. |
